# Design System Theme

 

This document outlines the core aesthetic and functional properties of our design system.

 

## Color Palette

 

Our color palette is defined with a `light` color mode.

 

-   **Primary Color:** `#0D9488` - A vibrant teal, serving as the brand's most distinctive chromatic color. It's ideal for primary calls to action, important interactive elements, and key branding accents.

-   **Secondary Color:** `#9D8EC1` - A muted lavender, supporting the primary color. It's used for less prominent UI elements, such as secondary buttons, chips, or complementary graphics.

-   **Tertiary Color:** `#F4B5D1` - A soft pink, providing an additional accent. This color is reserved for highlights, badges, notifications, or purely decorative elements to add visual interest.

-   **Neutral Color:** `#F2F4F3` - A very light grey, forming the base for backgrounds, surfaces, and non-chromatic UI components. It ensures readability and provides visual breathing room.

 

## Typography

 

Our typography system is built on a consistent and accessible font family.

 

-   **Headline Font:** `IBM Plex Sans Thai` - Used for all major headings and titles, ensuring strong visual hierarchy and impact.

-   **Body Font:** `Nunito Sans` - Applied to all paragraph text and long-form content, prioritizing readability and comfort.

-   **Label Font:** `Nunito Sans` - Employed for UI labels, input fields, and small descriptive text, maintaining consistency across interactive elements.

 

## Shape and Form

 

The aesthetic character of our UI elements is defined by their corner treatments.

 

-   **Roundedness:** `2` - A moderate level of roundedness (the default setting), balancing approachability with a clean, modern aesthetic.

 

## Spacing

 

Our spacing system governs the whitespace between and within UI components, contributing to overall visual balance and readability.

 

-   **Spacing:** `2` - A normal, balanced amount of whitespace, providing adequate separation between elements without making the interface feel too sparse or too dense.
